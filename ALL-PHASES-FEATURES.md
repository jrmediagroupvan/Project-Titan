# All-Phases Feature Map

## Operations
Dashboard, CRM, quotes, orders, production, file library, AI STL Developer, TITAN Figure Forge, inventory, market pricing, accounting, procurement and support.

## Workspace
Calendar, tasks, private and shared email, reports, business intelligence, notifications, AI Assistant and customer portal.

## System
Bambu printers, universal printer connectors, sales channels, automation rules, plugin center, integrations, activity log, update center, users, roles, permissions and business settings.

## Security boundaries
Private mailboxes remain private unless explicitly shared. The owner controls roles, permissions, integrations and destructive actions. Sensitive provider values are stored through encrypted configuration fields where supported. All public deployments should use HTTPS and unique production secrets.
