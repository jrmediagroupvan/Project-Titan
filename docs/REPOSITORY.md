# Official Repository

Project TITAN is maintained under the GitHub account:

```text
jrmediagroupvan
```

Official repository:

```text
https://github.com/jrmediagroupvan/Project-Titan
```

Clone using HTTPS:

```bash
git clone https://github.com/jrmediagroupvan/Project-Titan.git
cd Project-Titan
```

Set or correct the Git remote:

```bash
git remote set-url origin https://github.com/jrmediagroupvan/Project-Titan.git
git fetch origin
git branch --set-upstream-to=origin/main main
```

Verify:

```bash
git remote -v
git branch -vv
git status
```
