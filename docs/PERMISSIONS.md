# Users and Permissions

Supported role examples:

- OWNER
- ADMIN
- MANAGER
- STAFF
- PRODUCTION
- ACCOUNTING
- VIEWER

Project TITAN supports:

- Feature category assignments
- View, Create, Edit, and Delete controls
- Customer assignment restrictions
- Mailbox read/send permissions
- AI permissions
- Approval permissions
- Server-side enforcement

The OWNER retains full access and cannot be removed by lower roles.

Navigation hiding is not a security boundary. All routes and server actions must enforce permissions.
