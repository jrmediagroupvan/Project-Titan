# Production and Printers

Project TITAN supports production jobs, printer assignments, estimated time, material planning, notes, job status, and maintenance records.

## Bambu Slicing

TITAN should rely on real slicer output rather than bounding-box guesses. A trusted slicer agent can process STL or 3MF files using configured machine, process, and filament profiles.

## Bambuddy

Bambuddy may provide local Bambu status, camera, history, and controls. It is a separate project and requires its own installation, credentials, network access, and server-side adapter.

Do not expose printer access codes or full-control tokens in browser code.
