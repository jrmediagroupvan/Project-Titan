# TITAN AI

TITAN AI can use a shared server provider or private per-user provider settings.

Supported patterns:

- OpenAI
- OpenRouter
- OpenAI-compatible custom endpoints
- Local compatible models

## Security

- API keys are encrypted at rest.
- Saved keys are never returned to the browser.
- Users see only their own conversations.
- CRM context follows permissions and assigned-customer access.
- Sensitive actions require human approval.

## Permissions

Typical permissions include:

- AI chat
- AI images
- CRM search
- web research
- quote calculations
- file analysis
- action proposals
- action approvals

A ChatGPT subscription does not include OpenAI API usage.
