# Project TITAN Version 4.0

This is an updated README template preserving your branding while
documenting the new Version 4.0 features.

## New Features

-   Responsive desktop/mobile UI
-   Dark & Light themes
-   Optional QR-code two-step verification
-   Trusted devices & recovery codes
-   Security Center
-   One-click updater with rollback
-   Improved dashboard
-   AI Assistant
-   AI STL Developer
-   Bambu integration improvements

## Quick Install

``` bash
git clone https://github.com/jrmediagroupvan/Project-Titan.git
cd Project-Titan
cp .env.example .env
docker compose up -d
```

> Keep your existing images (`docs/images/Project-Titan.png`,
> `docs/images/Project-Titan-Details.png`, and `/public/installer.png`)
> in the same locations so they continue to render.
