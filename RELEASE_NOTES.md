# Project TITAN v8.0 — Operation FORGE

**Build:** 8.0.0  
**Codename:** Operation FORGE  
**Edition:** Commercial Enterprise Source Release

Operation FORGE combines the Project TITAN CRM, quoting, production, inventory, email, permissions, AI, printer, customer-portal, automation, quality, maintenance, API, security, and business-intelligence phases into one consistent release.

## Upgrade goals

1. Preserve existing Project TITAN business modules.
2. Add Figure Forge and advanced operating modules without replacing the core application.
3. Keep private user mailboxes isolated by default.
4. Give the Owner granular administrative and deletion privileges.
5. Keep the default quote markup at 13 percent.
6. Standardize all release metadata at version 8.0.0.

## External services

Gmail, image-to-3D generation, payment providers, shipping providers, marketplaces, and printer controls require valid credentials and compatible provider endpoints. The application must not fabricate successful external operations when a provider is unconfigured.
