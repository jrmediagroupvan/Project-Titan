# TITAN Commercial Feature Matrix

## Active in v2 beta

Authentication, users and roles, customer CRM, files, quotes, order conversion, order status, payment records, shipment records, production queue, printers, inventory, tasks, expenses, business reports, business settings, integration settings, audit log, backups, restore, health checks and GitHub updates.

## Requires provider credentials and live-account testing

Square payments/invoices/webhooks, Canada Post rates/labels/tracking, SMTP/Postmark email delivery, OpenAI quote assistance, Bambu bridge control, Moonraker/Klipper control and outbound webhooks.

## Planned hardening before public internet deployment

HTTPS reverse proxy, encrypted secrets at rest with external key management, CSRF and rate-limit review, two-factor authentication, password recovery email, immutable audit retention, automated integration tests, browser end-to-end tests, malware scanning for uploads, privacy/export/delete workflows, formal accounting exports, tax validation and disaster-recovery drills.
